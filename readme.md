## 📝 Descripción del Proyecto

¡Hola a todos! 👋 Este repositorio es el cuaderno digital de nuestra materia **Aplicaciones Informáticas** para estudiantes de **6to año de secundaria**.

Aquí no solo vamos a guardar código, sino que vamos a **documentar nuestro viaje** de aprendizaje en el mundo del Desarrollo de Software. Desde los conceptos más básicos hasta proyectos más complejos, este espacio será el reflejo de todo lo que construyamos juntos. ¡El objetivo es que este README y el repositorio evolucionen tanto como nosotros!

## 🎯 Objetivos del Curso

*   Comprender los fundamentos del **pensamiento computacional** y la **lógica de programación**.
*   Adentrarnos en los **conceptos fundamentales** del desarrollo de software.
*   Aprender a utilizar **Git y GitHub** como herramientas profesionales para el control de versiones.
*   Desarrollar aplicaciones sencillas y funcionales, aplicando buenas prácticas.
*   ¡Trabajar en equipo y colaborar en proyectos como lo hacen los verdaderos desarrolladores!
